# 无极助手

欢迎使用无极助手！这是一款专为天龙八部端游（怀旧、怀中坏、WG、源端私服等）设计的图色按键类辅助工具，一定程度上帮助您轻松游戏，提升游戏幸福感。

## 简介

无极助手 通过图像识别和自动化技术，实现自动打怪、技能释放、状态监测等功能，让您解放双手，轻松游戏。

## 主要功能

### 🎯 核心功能

- **自动打怪** — 智能识别怪物，支持打死换怪和抢怪两种模式，全自动攻击
- **技能调度** — 自动释放技能，智能冷却管理，最大化输出效率
- **多门派支持** — 覆盖多个门派技能配置，适配不同门派配置按键
- **快捷键控制** — 通过快捷键快速启停，操作便捷

### ⭐ 特色功能

- **自定义打特定怪/玩家** — 用户可自行截图目标怪物或玩家，软件智能识别并定点攻击
- **峨眉智能加血** — 支持给自己或队友自动加血，血量不足时精准释放治疗技能（清心、冲虚）
- **挂机防害刀** — 智能防护机制，安稳挂机降低意外风险
- **宣战玩家检测** — 自动检测宣战玩家，避免被人无刀击杀却毫无察觉
- **配置预设** — 针对不同场景（副本、野外、刷马贼等）保存独立配置，一键切换
- **刷马贼与马贼** — 支持刷马贼检测、自动组队、不当队长自动移交、验证码报警等全套功能
- **定点打怪** — 锁定打怪范围不乱跑，偏离自动回归，有效避免卡怪
- **死亡自动回点** — 角色死亡后自动返回挂机点继续挂机（高级功能）
- **定时退出游戏** — 支持设置定时自动退出，灵活控制游戏时长
- **智能状态检测** — 内置死亡检测、断线重连、验证码报警等多种状态监控，挂机更省心

### 🔐 安全保障

- **卡密授权** — 安全的授权验证系统
- **自动更新** — 保持软件最新版本
- **多实例限制** — 防止资源冲突
