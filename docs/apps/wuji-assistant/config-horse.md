# 刷马贼

刷马贼功能专为野外马匹及马贼场景设计，支持全套自动化流程。

## 功能概览

刷马贼功能集成在「挂机设置」→「刷马贼检测」面板中，启用后可实现：

- 自动检测马匹刷新
- 自动组队、移交队长
- 验证码弹窗报警
- 场景自动寻路

## 自动组队

启用自动组队后，软件会自动处理队伍相关操作：

1. **自动接受邀请**：收到组队邀请时自动同意
2. **移交队长**：若你是队长且配置了「不当队长」，会自动将队长移交给队友
3. **解散队伍**：若队伍仅剩自己且无人在附近，自动解散队伍
4. **无队伍回城**：长时间无队伍时自动返回苏州

## 验证码报警

刷马贼过程中弹窗验证码是常见问题，建议开启验证码报警：

- 检测到验证码时，软件将持续播放报警音
- 验证码消失后报警自动停止
- 可先点击「测试」按钮试听报警音，确认音量合适
- 听到报警后及时手动完成验证码，避免错过马匹

::: tip 提示
仅刷马贼不打怪时，验证码报警同样生效，不必担心遗漏。
:::

## 场景自动寻路

软件会自动识别当前场景，配合场景内 NPC 坐标实现自动寻路：

- 打完马后自动寻找下一处刷新点
- 通过双击场景内 NPC 触发寻路对话
- 寻路过程中自动下坐骑

## 截图保存马贼

刷马贼的关键在于让软件准确识别马贼，需要通过截图保存马贼特征：

1. 在游戏中遇到马贼时，选中该马贼
2. 点击软件上的「截图」按钮，保存马贼特征图片
3. 截图后点击「管理」按钮，可在管理面板中看到刚截图的马贼图片，确认保存成功
4. 后续软件将针对已保存的图片自动识别并优先攻击马贼

### 攻击模式设置

完成马贼截图后，还需要调整攻击模式，确保软件正确锁定马贼目标：

- **攻击对象**：选择「打特定怪」
- **攻击模式**：选择「打死换怪」

这样设置后，软件会优先匹配已截图的马贼，集中输出直至击杀，避免被其他怪物干扰。

## 刷马贼推荐配置

### 基础配置

| 配置项 | 推荐值 | 说明 |
|-------|--------|------|
| 刷马贼检测 | 开启 | 启用全部刷马贼功能 |
| 攻击对象 | 打特定怪 | 只攻击已截图的马贼 |
| 攻击模式 | 打死换怪 | 集中输出当前马贼直至击杀 |
| 验证码报警 | 开启 | 弹窗验证码及时提醒 |
| 自动组队 | 开启 | 自动处理组队相关操作 |
| 不当队长自动移交 | 开启 | 避免带队责任 |
| 无队伍自动回苏州 | 开启 | 无人时回城等待 |

### 技能配置

刷马贼建议使用高爆发技能配置，确保快速击杀：

- 攻击技能冷却设置较小的间隔
- 增益技能全程保持
- 回复技能按需开启

## 使用流程

1. 在苏州城外或马匹刷新点附近
2. 在游戏中选中马贼，点击「截图」按钮保存马贼特征
3. 点击「管理」确认马贼图片已保存
4. 将攻击对象设置为「打特定怪」，攻击模式设置为「打死换怪」
5. 勾选「刷马贼检测」并完成相关配置
6. 点击「开始」启动挂机
7. 听到验证码报警时及时处理

---

::: warning 注意
刷马贼场景下角色可能频繁移动，建议提前确认游戏窗口为标准尺寸（1024x768），避免点击位置偏移。
:::
