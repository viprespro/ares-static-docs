# 更新日志

## v1.4.1 (2026-08-30)

### ✨ 新功能

- **仅监测模式**：主界面新增「仅监测模式」开关，勾选后不自动打怪，只运行检测守护功能（死亡检测、宣战检测、验证码报警、断线重连、自动回复等，具体监测项以挂机设置中的开关为准）。适合使用游戏自带内挂挂机但要检测游戏状态，或想手动打怪但无需操心回复的场景
- 仅监测模式下断线重连成功后，自动恢复游戏内挂
- 运行中按钮与标题栏显示「⟳ 监测中」状态，与正常运行的「⟳ 运行中」区分
- 运行期间模式固定不变，修改后需停止并重新开始才生效；配置项已加入预设系统，可随预设保存/加载

### 🔧 优化

- 「鼠标左键点击窗口暂停按键」对峨眉加血同样生效，且支持配置无操作恢复时间（1-10 秒）
- 峨眉不再校验选怪后才释放技能，加血类技能无需选中怪物即可释放给队友

### 🐛 修复

- 修复定点打怪设置中「记录当前位置」按钮丢失的问题

## v1.3.0 (2026-07-05)

### ✨ 新功能

- **大区类型选择**：回点继续设置新增「大区类型」选择（怀旧大区/原始服），根据大区类型自动适配图标和坐标

- **功能权限控制**：新增功能级权限体系，支持基础功能和回点继续功能的独立权限控制

- 出窍回城城市选择动态显示/隐藏
