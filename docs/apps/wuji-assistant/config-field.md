# 野外挂机

野外挂机涵盖世界地图野外、门派地图、副本等多种场景，合理配置可大幅提升挂机效率和安全性。

## 基础配置

### 攻击模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 抢怪模式 | 快速扫描并攻击范围内所有怪物 | 怪物密集、刷新快的区域 |
| 打死换怪 | 击杀当前目标后再切换下一个 | 怪物较分散、需要集中输出的区域 |

### 技能调度

- 配置核心输出技能，设置合适的释放间隔
- 增益 BUFF 技能保持全程覆盖
- 控制技能按需配置，避免浪费冷却

## 打特定怪/玩家

野外场景中常常需要针对特定目标：

- **打特定怪**：截图目标怪物特征，优先攻击（适用于抢精英怪、特定掉落怪等）
- **打特定玩家**：截图目标玩家特征，用于 PVP 场景
- **忽略怪物**：添加不攻击的怪物（如巡逻 NPC、任务怪等）

## 峨眉加血

峨眉门派挂机必备功能：

- **自我治疗**：血量低于设定阈值时自动加血
- **队友治疗**：检测到队友血量不足时自动治疗
- **加血优先级**：可按 自己 > 队长 > 其他队友 排序
- 支持配置加血技能快捷键和释放间隔

## 定点打怪

防止角色跑出安全区域或卡在地形中：

1. 将角色移动到理想挂机位置
2. 勾选「定点打怪」，点击「记录当前位置」
3. 设置「回点距离」（如 100 像素）
4. 角色偏离后自动寻路回归

::: tip 提示
建议将回归距离设置为当前区域半径的 70%-80%，既能覆盖大部分怪物刷新点，又不会跑得太远。
:::

## 死亡自动回点（高级功能）

角色死亡后自动返回挂机位置继续挂机，减少挂机中断时间。

### 配置步骤

1. 在「回点继续」设置中勾选「启用回点继续」
2. 选择「大区类型」：怀旧大区 / 原始服
3. 选择回点城市（推荐洛阳）
4. 配置当前门派的回点坐标
5. 设置最大尝试次数（如 3 次）

### 工作流程

1. 角色死亡 → 自动出窍到地府
2. 随机等待模拟真实操作
3. 到达地府后自动回到设定城市
4. 从城市自动寻路到回点坐标
5. 到达后恢复挂机

::: warning 注意
回点继续为高级功能，需要单独的功能权限。使用前请确认授权已包含该功能。
:::

## 宝宝出战

- 开启「宝宝出战」后，软件会检测宝宝是否处于出战状态
- 连续 3 次检测未出战，自动使用快乐度道具补充
- 需要前台操作，请谨慎开启

## 回复设置

配置角色自动回复的策略：

- **血量回复**：设置触发加血的 HP 百分比阈值
- **蓝量回复**：设置触发回蓝的 MP 百分比阈值
- **回复优先**：可设置血量优先还是蓝量优先
- **回复技能**：绑定对应的回复技能快捷键

## 断线重连

启用后软件会自动检测断线画面并点击重连：

- 检测到断线后自动重连
- 重连成功后自动恢复挂机
- 重连期间会短暂使用鼠标，请勿干预

## 宣战检测

开启宣战检测后，软件会实时监控附近玩家的宣战行为，让你安心挂机：

- **自动检测宣战玩家**：扫描画面中的宣战图标/状态
- **即时提醒**：检测到宣战后触发提醒
- 避免被人无刀击杀却毫无察觉，留出反应时间

## 挂机隐藏

将游戏窗口移到屏幕下方仅保留标题栏，不影响挂机运行，同时降低被路人注意的概率：

- 点击「挂机隐藏」按钮即可隐藏窗口
- 再次点击恢复原位
- 隐藏期间挂机功能正常运行

## 窗口排列

多开时使用窗口排列功能整齐布局：

- 点击「窗口排列」或使用快捷键 `Ctrl + Alt + A`
- 支持多种排列模式（左上→右下、左上→右上等）
- 方便同时监控多个角色

## 点击暂停

开启「点击窗口暂停按键」后：

- 点击游戏窗口即暂停按键发送
- 1 秒无操作后自动恢复
- 适合需要临时手动操作的场景

## 主城内暂停

勾选「主城内不执行按键」后，角色进入主城（洛阳、苏州、大理等）时自动暂停按键，出城后自动恢复，避免在主城内误操作。

## 推荐配置预设

### 常规野外挂机预设

| 配置项 | 推荐值 |
|-------|--------|
| 攻击模式 | 抢怪模式 |
| 定点打怪 | 开启 |
| 宣战检测 | 开启 |
| 断线重连 | 开启 |
| 回点继续 | 按需开启 |
| 宝宝出战 | 按需开启 |

### 峨眉专用预设

| 配置项 | 推荐值 |
|-------|--------|
| 攻击模式 | 打死换怪 |
| 峨眉加血 | 开启 |
| 给自己加血 | 开启 |
| 给队友加血 | 开启 |
| 定点打怪 | 开启 |
| 断线重连 | 开启 |

::: danger 警告
野外挂机时请注意账号安全，避免在完全无人值守的情况下长时间挂机。建议定期检查挂机状态。
:::
