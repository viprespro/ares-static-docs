# 野外挂机

野外挂机涵盖世界地图野外、门派地图、副本等多种场景，合理配置可大幅提升挂机效率和安全性。

## 基础配置

### 攻击模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 抢怪模式 | 快速扫描并攻击范围内所有怪物 | 怪物密集、刷新快的区域 |
| 打死换怪 | 击杀当前目标后再切换下一个 | 怪物较分散、需要集中输出的区域 |

### 技能调度

- 配置核心输出技能，设置合适的释放间隔
- 增益 BUFF 技能保持全程覆盖
- 控制技能按需配置，避免浪费冷却

## 防害刀

门派副本或者野外挂机中，防害刀是必不可少的，懂的都懂。

### 方式1 - 不打玩家
- 脚本设置中，打怪方式选择为打死换怪
- 攻击对象选择为不打玩家

说明：
- 打死换怪下，强制换怪时间可以设置为略微大于你预估能秒掉怪物的时间，比如你预估能秒掉怪物的时间是 10 秒，那么强制换怪时间可以设置为15秒，防止界面ui卡怪会会一直不打怪的情况
- 通常挂机不需要使用技能，可以不设置技能
- 不打玩家，选到时玩家或玩家宝宝会自动跳过，注意需设置游戏视角拉远，不清楚的可联系管理员
- 由于增加了识别 选怪速度相比扫射会慢一些，但是安全性会更高，100%可以避免被害刀
- 建议创建好之后可以保存为一种预设，方便下次直接使用

### 方式2 - 打特定怪
- 脚本设置中，打怪方式选择为打死换怪
- 攻击对象选择为打特定怪，截图挂机位置的怪物即可

说明：
- 这种方式只会打特定怪自然不会打其他怪和玩家，也就避免了被害刀，100%安全，缺点就是如果不同的挂机点需要打不同的怪，需要截图一次
- 不需要调节视角
- 由于增加了识别 选怪速度相比扫射会慢一些，但是安全性会更高，100%可以避免被害刀
- 建议创建好之后可以保存为一种预设，方便下次直接使用

### 方式2 - 抢怪模式
- 脚本设置中，打怪方式选择为抢怪模式
- 挂机设置中，宣战检测设置需要勾选，也就是检测到被人宣战会自动检测，避免被害刀
  
![alt text](./imgs/image.png)
- 原理就是检测到有人宣战，会认为是有人害刀，在一定时间后自动切换为方式1中的不打玩家，一段时间后自动恢复

说明：
- 这种方式优点是快速抢怪，即使有别人耗点也能抢到怪，同时保障了被害刀的安全性
- 需要调整设置界面ui，以及视角拉远，可咨询管理员设置方式
- 有一定几率被害刀，但是几率不高，可以自行测试一下

## 定点打怪

防止角色跑出安全区域或卡在地形中：

1. 将角色移动到理想挂机位置
2. 勾选「定点打怪」，点击「记录当前位置」
3. 设置「回点距离」（如 100 像素）
4. 角色偏离后自动寻路回归

::: tip 提示
建议将回归距离设置为当前区域半径的 70%-80%，既能覆盖大部分怪物刷新点，又不会跑得太远。
:::

## 死亡自动回点（高级功能）

角色死亡后自动返回挂机位置继续挂机，减少挂机中断时间。

### 配置步骤

1. 在「回点继续」设置中勾选「启用回点继续」
2. 选择「大区类型」：怀旧大区 / 原始服
3. 选择回点城市（推荐洛阳）
4. 配置当前门派的回点坐标
5. 设置最大尝试次数（如 3 次）

### 工作流程

1. 角色死亡 → 自动出窍到地府
2. 随机等待模拟真实操作
3. 到达地府后自动回到设定城市
4. 从城市自动寻路到回点坐标
5. 到达后恢复挂机

::: warning 注意
回点继续为高级功能，需要单独的功能权限。使用前请确认授权已包含该功能。
:::

## 宝宝出战

- 开启「宝宝出战」后，软件会检测宝宝是否处于出战状态
- 连续 3 次检测未出战，自动使用快乐度道具补充
- 需要前台操作，请谨慎开启

## 回复设置

配置角色自动回复的策略：

- **血量回复**：设置触发加血的 HP 百分比阈值
- **蓝量回复**：设置触发回蓝的 MP 百分比阈值
- **回复优先**：可设置血量优先还是蓝量优先
- **回复技能**：绑定对应的回复技能快捷键

## 断线重连

启用后软件会自动检测断线画面并点击重连：

- 检测到断线后自动重连
- 重连成功后自动恢复挂机
- 重连期间会短暂使用鼠标，请勿干预

## 宣战检测

开启宣战检测后，软件会实时监控附近玩家的宣战行为，让你安心挂机：

- **自动检测宣战玩家**：扫描画面中的宣战图标/状态
- **即时提醒**：检测到宣战后触发提醒
- 避免被人无刀击杀却毫无察觉，留出反应时间

## 挂机隐藏

将游戏窗口移到屏幕下方仅保留标题栏，不影响挂机运行，同时降低被路人注意的概率：

- 点击「挂机隐藏」按钮即可隐藏窗口
- 再次点击恢复原位
- 隐藏期间挂机功能正常运行

---

::: danger 警告
野外挂机时请注意账号安全，避免在完全无人值守的情况下长时间挂机。建议定期检查挂机状态。
:::
